# Tropico Advisor

Companion application for Tropico 6.

## Projects

- `Tropico.SaveParser` - Tropico 6 save file parser
- `Tropico.Analysis` - Island analysis and recommendation engine
- `Tropico.Data` - Local historical data storage
- `Tropico.Cli` - Save inspection and reverse-engineering CLI
- `Tropico.Desktop` - Avalonia desktop application
